# ♿ RouteAble

Веб-приложение для отображения информации о доступности городской инфраструктуры для людей с ограниченными возможностями здоровья (ОДА).

## 📖 О проекте

В современном городе многие объекты инфраструктуры остаются недостаточно адаптированными для людей с ограниченной мобильностью. Отсутствие информации о наличии пандусов, лифтов или других средств доступности может существенно осложнять передвижение и ограничивать самостоятельность человека.

**RouteAble** — это проект, направленный на решение данной проблемы. Приложение предоставляет пользователям актуальную информацию о доступности жилых домов и объектов городской инфраструктуры, помогая заранее оценить удобство посещения нужного места и построить более комфортный маршрут.

Проект разрабатывается как социально значимый инструмент, который способствует созданию более доступной и инклюзивной городской среды.

---

## 🎯 Цели проекта

Основными целями проекта являются:

* повышение доступности городской инфраструктуры;
* улучшение качества жизни людей с нарушениями опорно-двигательного аппарата;
* предоставление достоверной информации о доступности объектов;
* снижение барьеров при самостоятельном передвижении по городу;
* поддержка развития концепции «доступной среды».

---

## 🚀 Функциональные возможности

Система позволяет:

### Для пользователей

* просматривать объекты на карте города;
* получать информацию о доступности зданий;
* узнавать о наличии лифтов;
* просматривать характеристики лифтов;
* получать сведения о наличии пандусов;
* просматривать параметры пандусов;
* оценивать удобство посещения объекта для маломобильных граждан.

### Для администраторов

* добавлять новые объекты;
* редактировать существующие записи;
* удалять устаревшую информацию;
* управлять данными через административную панель Django;
* контролировать актуальность размещённой информации.

## 🏗 Архитектура проекта

Проект реализован по клиент-серверной архитектуре.

### Backend

Серверная часть отвечает за:

* хранение данных;
* обработку запросов пользователей;
* предоставление REST API;
* управление правами доступа.

Используемые технологии:

* Python
* Django
* Django REST Framework

### Frontend

Клиентская часть обеспечивает:

* отображение пользовательского интерфейса;
* взаимодействие с картой;
* отображение информации об объектах.

Используемые технологии:

* HTML5
* CSS3
* JavaScript

### База данных

Для хранения данных используется:

* SQLite (по умолчанию)

При необходимости проект может быть легко перенесён на PostgreSQL или другую СУБД.

## 📊 Хранимые данные

Для каждого объекта могут храниться следующие сведения:

| ------------------------- | --------------------------------------- |
| Адрес                     | Местоположение объекта                  |

## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd map
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация окружения

Windows:

```bash
venv\Scripts\activate
```

PowerShell:

```bash
venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Выполнение миграций

```bash
python manage.py migrate
```

### 6. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

Административная панель:

```text
http://127.0.0.1:8000/admin/
```
